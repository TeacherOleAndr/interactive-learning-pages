# Interactive Learning Pages

Колекція автономних інтерактивних навчальних сторінок і тренажерів.

## Структура

Кожна навчальна тема розміщується в окремій теці за схемою:

```text
interactive-learning-pages/
├── index.html
├── math/
│   └── inequalities-intervals/
│       └── index.html
└── README.md
```

## Доступні модулі

### Математика

- **Нерівності та числові проміжки — 9 клас**
  - інтерактивна теорія;
  - відповідність «нерівність ↔ числова пряма ↔ проміжок»;
  - побудова множини розв'язків;
  - зворотні задачі;
  - лінійні нерівності;
  - самоперевірка.

Шлях: `math/inequalities-intervals/index.html`

## Принципи проєкту

- автономні HTML-сторінки без обов'язкового бекенду;
- адаптивність для комп'ютера, планшета і телефона;
- інтерактивність замість статичного конспекту;
- можливість додавати нові теми як незалежні модулі;
- придатність для публікації через GitHub Pages.
