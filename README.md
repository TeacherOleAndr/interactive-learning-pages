# Interactive Learning Pages

Колекція автономних інтерактивних навчальних сторінок і тренажерів.

## Навігація

Головна сторінка — **9 клас** → **Алгебра** або **Геометрія**.

- `math/algebra/index.html` — каталог тем з алгебри: «Нерівності та числові проміжки».
- `math/geometry/index.html` — каталог тем з геометрії: «Розв’язування трикутників».
- Адреси самих тренажерів залишено без змін, щоб зберегти наявні посилання.

## Принципи проєкту

- автономні HTML-сторінки без обов'язкового бекенду;
- адаптивність для комп'ютера, планшета і телефона;
- інтерактивність замість статичного конспекту;
- можливість додавати нові теми як незалежні модулі;
- придатність для публікації через GitHub Pages.

### Розв’язування трикутників

- Українські позначення: ССС, СКС, КСК, ККС, ССК;
- обчислення сторін і кутів за трьома відомими елементами;
- неоднозначний випадок ССК з двома можливими розв’язками;
- автоматичне креслення, площа, периметр і пояснення розв’язання.

Шлях: `math/triangle-solving/index.html`

## Модуль «Розв’язування трикутників» — інтерактивні можливості

- Теоретичні покрокові алгоритми ССС, СКС, КСК, ККС, ССК без числових даних, з альтернативними шляхами.
- Позначення: вершини A, B, C; довжини сторін a, b, c; величини кутів α, β, γ.
- Колір станів: синій — дано, червоний — шукаємо зараз, зелений — знайдено раніше.
- Числовий розв’язувач: усі допустимі варіанти, креслення для кожного кроку, периметр і площа; значення показано до сотих із «≈», а внутрішні обчислення виконуються без проміжного округлення.
- Самоперевірка: нові задачі різних типів, вибір шуканого елемента й методу, вибір відповідної пари для теореми синусів, покрокова перевірка, скасування кроку, три режими навчання. Елементи можна обирати кнопками або на SVG-кресленні.

Шлях: `math/triangle-solving/index.html`.
