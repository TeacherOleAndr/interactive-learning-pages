Тригонометричні рівняння

Одиничне коло → формула загального розв’язку → графік функції

Як знайти корені рівняння?

Змінюй значення a. На одиничному колі пряма показує розв’язки в межах одного оберту, а на графіку від −2π до 2π видно, як ці корені повторюються. Увімкни потрібні функції — для кожної використовується той самий рівень a.

На колі різні точки відповідають різним положенням кута за один оберт. На графіку корінь рівняння — це значення x на горизонтальній осі, а не значення функції в точці перетину.

Рівняння з синусом і косинусом

0,50

Одиничне коло

Кольоровий відрізок від 0 до a на осі Oy показує sin x = a, а на осі Ox — cos x = a. Дуги позначають шукані кути.

Графік від −2π до 2π

Загальні розв’язки для синуса й косинуса

sin x = a
x=(−1)narcsin(a)+πn

n ∈ ℤ, −1 ≤ a ≤ 1; arcsin(a) ∈ [−π/2; π/2].

cos x = a
x=±arccos(a)+2πn

n ∈ ℤ, −1 ≤ a ≤ 1; arccos(a) ∈ [0; π].

Якщо |a| > 1, жоден із цих двох типів рівнянь не має дійсних коренів. Позначення «±» означає дві сім’ї значень, які іноді збігаються.

Рівняння з тангенсом і котангенсом

1,0

Одиничне коло і дотичні

Для тангенса відрізок a лежить на дотичній x = 1, для котангенса — на дотичній y = 1. Дуги від додатної півосі Ox позначають шукані кути.

Графік від −2π до 2π

Загальні розв’язки для тангенса й котангенса

tg x = a
x=arctg(a)+πn

n ∈ ℤ, a ∈ ℝ; arctg(a) ∈ (−π/2; π/2).

ctg x = a
x=arcctg(a)+πn

n ∈ ℤ, a ∈ ℝ; arcctg(a) ∈ (0; π).

Тангенс і котангенс мають період π. На графіку пунктиром показані асимптоти, а порожніми кружками на осі x — значення аргументу, в яких відповідна функція не визначена.

Особливі випадки

sin x = 0 ⇒ x = πncos x = 0 ⇒ x = π/2 + πntg x = 0 ⇒ x = πnctg x = 0 ⇒ x = π/2 + πnsin x = 1 ⇒ x = π/2 + 2πnsin x = −1 ⇒ x = −π/2 + 2πncos x = 1 ⇒ x = 2πncos x = −1 ⇒ x = π + 2πn

Тут і в усіх формулах n ∈ ℤ. У цих прикладах загальний запис можна спростити, не втрачаючи коренів.

Чому для синуса й косинуса зустрічається 2πn, а для тангенса й котангенса — πn? За оберт на 2π положення точки повторюється; значення тангенса й котангенса повторюються вже через π. Для sin x = a компактний запис через (−1)ⁿ поєднує дві симетричні сім’ї коренів.
